# Student Management System in C++

A console-based Student Management System developed in C++ as part of my Programming Fundamentals (PF) learning journey.

This project manages student records and academic performance for three subjects: Programming Fundamentals (PF), AICT, and Calculus.

## Features

- Add new student records
- Display all student records in a formatted table
- Search students by ID
- Update student marks
- Delete student records
- Calculate average marks, GPA, and grades
- Identify the student with the highest GPA
- Calculate subject-wise average marks
- Count pass and fail students
- Save student records to a text file
- Load saved records from a text file
- Automatically load records when the program starts
- Automatically save records when the program exits
- Validate numeric inputs and subject marks
- Prevent duplicate student IDs

## Concepts Used

- C++ programming fundamentals
- One-dimensional and two-dimensional arrays
- Functions and modular programming
- Loops and conditional statements
- Switch-case menu
- File handling using `ifstream` and `ofstream`
- Input validation
- Formatted output using `iomanip`

## How to Run

1. Download `StudentManagementSystem.cpp` from this repository.
2. Open the file in a C++ IDE, such as Dev-C++ or Visual Studio Code with a configured C++ compiler.
3. Compile and run the program.
4. Use the menu to manage student records.

The program stores records in `StudentData.txt` in its working directory. Keep this file available if you want to retain previously saved records.
